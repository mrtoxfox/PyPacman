# Bonus System Prompts
I'd like to add new bonuses to the game that will appear randomly on the map. Analyze the project and prepare detailed implementation plans in markdown format for following tasks: 

1. Create a universal bonus system that will generate bonuses randomly on the map grid in the same place where regular points are generated. The system should control the duration of bonuses and their effects. Bonuses should be independent entity that can affect Ghost, Packman, the map, or other game mechanics, and should not be integrated to the other entities such as Ghosts and pacman, they should affect only external arrtibutes. In addition, bonuses should have settings that determine how many of them can appear on the map at the same time and the time of the bonus appearance. 
2. Add a bonus that freezes the ghost for 10 seconds. 
3. Add a bonus that slows the ghost down by half for a few seconds. Save all prompts in the `prompts` folder in the project's root directory.
